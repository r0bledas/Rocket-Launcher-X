Aviso de privacidad

Rocket Launcher / Rocket Launcher X · Última actualización: 17 de octubre de 2026

Este aviso describe cómo la aplicación Rocket Launcher, también publicada como Rocket Launcher X (la misma aplicación, la app), trata la información de sus usuarios. [[LEGAL_NAME]], [[POSTAL_ADDRESS]] es el responsable del tratamiento.

1. Datos que tratamos

  • Configuración local: nombres, íconos y esquemas de URL que agregas, y ajustes de apariencia. Se guardan en tu dispositivo y no se nos transmiten. Si agregas una app del catálogo, su nombre puede enviarse a la API de Apple (iTunes) para obtener el ícono, salvo que lo desactives en Ajustes.
  • Analítica (seudónima, activada por defecto, desactivable): mientras esté activada se envían eventos de lanzamiento con el nombre de la app y el esquema de URL completo, incluidos los esquemas personalizados que escribas, el número de widget y la ranura, la hora local del día, y un identificador de instalación seudónimo. Puedes desactivarla, restablecer el identificador o solicitar su eliminación desde Ajustes → Privacidad.
  • Publicidad: usamos Google AdMob. Con tu consentimiento y, en iOS, si lo permites mediante App Tracking Transparency, la publicidad puede personalizarse; en caso contrario se muestra de forma no personalizada.
  • Compras: procesadas por Apple; no recibimos tus datos de pago.

2. Finalidades

Analítica (interés legítimo, desactivable), publicidad, y funcionamiento y verificación de compras y desbloqueos.

3. Transferencias de datos (terceros)

Google (AdMob) para publicidad; Apple (iTunes Search) para íconos; GitHub para el catálogo comunitario; nuestro servidor de analítica autoalojado cuando la analítica está activa; y Google al usar la búsqueda dentro de la app. Consulta la política de privacidad (EN) para el detalle.

4. Derechos ARCO

Puedes ejercer tus derechos de acceso, rectificación, cancelación y oposición enviando una solicitud al correo de contacto. Para la eliminación de datos de analítica, copia tu identificador (Ajustes → Privacidad) e inclúyelo.
